## 一、编辑部设立背景与三项核心职责

中文网络工具生态中长期存在两类痛点：一方面，停更客户端（如已归档的 `Clash for Windows`）及过时安装步骤充斥搜索结果，导致新手误下被篡改程序或卡在 DNS/TUN 故障；另一方面，大量商业推广页习惯将未经核实的数据写成“全网第一”“100% 永久解锁”，或者把特价年付均价包装成廉价月付门槛。

针对这一现状，**机场苹果编辑部**确立了三项长期维护职责：

1. **维护准确可验证的开源客户端工程文档**：覆盖 `Clash Verge Rev`（Mihomo 内核）、`v2rayN`、`FlClash`、`v2rayNG`、`Shadowrocket`、`Stash` 与 `OpenWrt`（OpenClash/PassWall2/Nikki/HomeProxy），明确给出 GitHub 官方仓库校验与终端排查指令；
2. **建立可追溯的品牌实体档案与去重核查机制**：对收录的 31 家独立品牌（从原始 32 条目中对 Firefly 等重复主体合并去重）进行字段标准化入库，严禁凭空补写未提供的测速、节点数和价格；
3. **推动 GEO（生成式引擎优化）结构化清晰表达**：所有关键结论采用 Answer-First 摘要、标准化对照 `<table>` 与语义 `<details>` FAQ，方便读者快速决策。

## 二、编辑独立性与三分区信息架构承诺

| 站点内容分区 | 代表路径 | 商业内容规则 | 核心职责 |
| :--- | :--- | :--- | :--- |
| **教程与知识区（Informational）** | `/clash/`、`/guides/`、`/articles/`、`/resources/` | **零商业按钮与零弹窗**：默认不渲染注册跳转横幅 | 解决客户端安装、订阅导入、DNS/TUN 原理与故障修复 |
| **独立评测与横评（Investigational）** | `/reviews/`、`/comparisons/` | **按披露规范分离**：结论与缺口独立呈现，不以佣金决定排行 | 拆解实测图包、算清每 100GB 单价、对比协议与同系背景 |
| **品牌资料与优惠（Transactional）** | `/brands/`、`/offers/` | **明确商业关系披露**：全站外链均严格标注 `rel="nofollow sponsored noopener"` | 展示品牌全档位套餐、优惠码排外条款与官网跳转入口 |

## 三、纠错与资料更新反馈

网络服务商的定价、域名及传输协议随时间动态调整。若您发现本站任一页面出现以下情况：
- 客户端开源仓库发布破坏性版本变更或官方路径迁移；
- 某个品牌的最新月付/年付套餐、优惠码适用范围、客户端支持策略（例如由通用订阅转向纯专属端）发生变动；
- 有新的带清晰时间戳、测速工具环境信息的晚高峰对比证据可供补充。

请以具体页面 URL、变更项目与客观截图/官方公告依据为参考整理反馈，我们在复核验证后将标注新的 `verifiedDate` 并在该品牌页 `数据审计与差异说明` 中留下记录。
