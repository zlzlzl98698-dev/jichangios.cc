## 一、原始资料来源与四级可信度标签

本站 31 家独立品牌档案与 18 篇评测页面的核心证据来自四组可交叉印证的原始数据集，并据此对每家品牌与每项解锁条目实施分级标注：

| 数据可信度标签 | 判定标准 | 典型代表与读图要求 |
| :--- | :--- | :--- |
| **`Measured`（独立实测）** | 具备 `MiaoKo`、`MAI-TEST-BOT` 或站长实测原图及完整参数（标明测速时间、线程数及落地节点异常点，包括 `0B` 失效节点） | 如光速云（`2026-08-19` 五图 + `08-11`）、极连云 / 光年梯 / 速界 / 宇宙云（`2026-08-11` 批次） |
| **`Partial`（部分实测 / 单次基准）** | 拥有 `2026-10-19` 非晚高峰基准参考或基础报价表，但缺少独立三网大图或逐项流媒体截图 | 提醒读者区分“非晚高峰单次参考”与“本地宽带晚九点连续表现” |
| **`Vendor Claimed`（品牌自述 / 待核实）** | 仅来源于服务商官网简介文本、尚未匹配独立实测截图的能力描述或速率承诺 | 明确标红区分，如实提醒“系厂商自述，须自行月付验证” |
| **`Historical`（历史存档）** | 信息快照采自 `2026-08-09` 及以前、超过 90 天未经近 30 日复测的档案 | 如灵动云、浪网、EdgeNova，强制附带时效提醒与防直接长付建议 |

## 二、测速数据与解锁校验的技术标尺

1. **区分机房并发测试与家用真实体验**：
   - `2026-08-11` 与 `2026-08-19` 原图主要运行于珠海联通 `5Gbps / 9Gbps` 32 线程测速台，适合观测服务端带宽峰值上限、节点在线率（如实保留 `0.00B` 失效节点）及 `TLS RTT / HTTPS` 握手健康度；
   - 测试时间窗口严格区分 **下午闲时（如 14:38、15:32）** 与 **夜间/晚高峰窗口（如 21:04、22:46）**，不拿下午闲时跑分冒充晚高峰承诺。
2. **解锁结果的精细颗粒度**：
   - 坚决弃用笼统的“全流媒体/全 AI 支持”表述，精细拆分记录 `仅 APP(HK)`、`YouTube 送中(CN)`、`IP 识别偏移（如 ES）` 与 `视节点而定`；当某项测试图仅测速率未测解锁时，解锁状态一律标 `Not Tested`。

## 三、定价、优惠与实体审计准则

1. **严禁混淆“年付折算均价”与“真月付价格”**：所有将 ¥79–¥99 年付小包除以 12 宣传的月均数值，在数据库和表格中一律拆分为独立字段（`lowestAnnualEquivalentMonthly` vs `lowestMonthlyPrice`），防止低门槛预期误判。
2. **实名去重合并与同系关联披露**：对同名或同域同构实体（如原始文档中第 8 项 Firefly 与文末历史 Firefly 萤火虫记录）执行去重合并；对于文档有记载的同系/关联后台关系（如 Firefly 与微风/飞鸟/一云梯）予以客观标注，帮助用户避免双线热备买在同一家底层上。
3. **链接与代码格式合规审计**：对 `云界线`、`环球梯`、`榴莲云` 等原文存在哈希符或斜杠差异的注册链接以及同一品牌双版本优惠码冲突，原文记录在 `数据审计与差异说明` 中。
