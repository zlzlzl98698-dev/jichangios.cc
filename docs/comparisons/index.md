## 二、横向比较遵循的五项固定标尺

为了避免出现“拿 A 家的年付月均价去比 B 家的标准月付价”这类误导性对比，本站所有对比文章统一执行以下五项标尺：

| 对比维度 | 统一核对口径 | 为什么要卡死这项口径 |
| :--- | :--- | :--- |
| **1. 计价标准** | 明确拆分「真月付最低价格」vs「年付一次性总价除以 12」 | 避免用户想试用 1 个月却发现必须一次掏出近百元年费且不可退 |
| **2. 客户端开放度** | 区分「支持第三方订阅」「双支持」「仅专属客户端」 | 决定能否导入 Clash Verge Rev、Shadowrocket 与 OpenWrt 软路由 |
| **3. 实测资料核实度** | 区分「2026-08-19/08-11 真实截图原图」「10-19 单次数据」与「缺测速」 | 让读者明确分辨哪些结论来自实测档案、哪些仍是待补充空白 |
| **4. 解锁边界标注** | 不笼统写“全解锁”，拆分标注 `仅 APP(HK)` / `视节点而定` / `待核实` | 避免依赖网页版 ChatGPT/Gemini 的用户买回家才发现部分区域不可用 |
| **5. 优惠限制核查** | 单独写明折扣码是否排除「特价年付小包」与「永久不限时包」 | 防止结账发现优惠码提示不适用商品的心理落差 |
