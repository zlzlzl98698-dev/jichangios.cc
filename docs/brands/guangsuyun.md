## 光速云 自研端与 Clash/小火箭通用订阅导入指引

- **接入模式**：`自研客户端 + 支持 Clash / Shadowrocket 等第三方订阅导入`（已核实兼顾「官方一键端」与「第三方通用订阅」）
- **核心协议栈**：`VLESS / Shadowsocks（见 2026-08-19 测速图） / AnyTLS（见 2026-08-19 测速图）` · **适配参考**：自研客户端、Clash Verge Rev、Shadowrocket、Mihomo 系客户端
- **配置建议**：
  1. **桌面与多平台优先选 Clash Verge Rev / FlClash**：进入用户面板复制「Clash 订阅链接」导入即可，避免安装早已停更的 `Clash for Windows`；建议开启定期自动更新（如 720 分钟），保持节点列表同步。
  2. **iOS / 软路由扩展**：已购美区 `Shadowrocket / Stash` 或部署 `OpenWrt (OpenClash / Nikki)` 的用户，均可直接使用通用订阅接入并在本地编写分流规则；家人或纯新手则可先安装官网桌面/移动一键端。
  3. **AI 与流媒体分组习惯**：日常使用 ChatGPT / Claude / Gemini 时，建议在客户端内使用 `select` 手动锁定新加坡、日本或美国节点，不要开自动延迟跳区。
