## 一、决定稳定性的四大技术底座

### 1. 跨境段传输架构：IEPL / IPLC vs 公网直连/普通中转
- **公网直连**：用户流量直接在公网跨越国际边界，晚高峰及敏感期间极易遭遇严重丢包或端口阻断。
- **IEPL / IPLC 跨境专线**：用户先加密连接到国内 BGP 入口机房，再通过运营商级别的**二层/三层内网物理专线**直接抵达香港、日本或新加坡落地机，跨境核心段不走拥堵公网，延迟抖动与丢包率大幅降低。

### 2. 国内入口：三网 BGP 与运营商差异
不同家庭宽带（电信、联通、移动）接入同一台入口机房的路由质量往往不同。在光速云 `2026-08-19` 的三网对照 MiaoKo 测试图中就能直观看到：**同一组 62 个 Shadowsocks 节点下，长沙电信与广西移动 HTTPS 延迟大多处于 80–240ms、均速 35–53MB/s；而河北联通样本中部分节点 HTTPS 延迟升高到 300–1300ms**。这证明：哪怕同为专线机场，不同省份运营商也必须经过至少一周的本地晚高峰真实验证。

### 3. 协议与拥塞控制能力
- **VLESS（含 Vision / Reality）** 与 **Trojan**：抗识别能力与高并发稳定性成熟，几乎被全站主流专线机场采用；
- **Hysteria 2**（如一翻云配备）：基于 QUIC UDP 协议与 Brutal 拥塞控制，在本地 Wi-Fi 弱网或跨境轻微丢包环境下吞吐保持能力更强（注意部分企业内网会限制 UDP 端口，此时可切回 VLESS/Trojan）。

### 4. 运营沉淀周期核查（31 家品牌时间轴）
- **2020 年起运营（6 年+ 跨周期老牌）**：**光速云、星岛梦**（两者均提供通用订阅与不限时包，抗风险经验相对充足）。
- **2023 年起运营（3 年+ 成熟品牌）**：**暮光加速、飞猫云、微风网络、二猫云、唯兔云**。
- **2024–2026 年上线**：如极连云、速界、可信云、隐形人（2024），U1S1、一翻云、梯子云、灵猫网络、光年梯、无忧链接、灵动云（2025），SOGO 云、全球云（2026）。新品牌往往价格/协议激进，但长期稳定度仍需按月付逐步检验。

## 三、怎么看懂“晚高峰稳定性”测试证据？

1. **核查测试时间戳**：
   - 在《32家机场品牌清单.txt》中，`2026-10-19` 汇总表明确标注了 **`（非晚高峰）`**，所以其中的 500Mbps+ 只能作为链路能力上限参考，不能直接当成晚 21 点实速。
   - 而在 `2026-08-11` 实测图包与 `2026-07` 图中，真正落于晚间活跃窗口的包括：**宇宙云（21:04）**、**无忧链接（21:40/21:47）**、**U1S1（22:33）** 与 **极连云（22:46）**，观察这些晚间图时重点看香港/新加坡的 **HTTPS 延迟绿/黄分布** 与 **0B 节点占比**。
2. **关注 0B/KB 失败节点率**：成熟稳定的机场在 50–70 个节点中偶尔出现 1–2 个临时维护节点属常态（如宇宙云香港01 0.00B、极连云专线01 0B），关键看同地区（如香港其余 14–19 个节点）是否依旧保持高可用以供随时切换。

## 四、高可用“双机场容灾”黄金搭配法则

哪怕再老牌的专线机场，也可能遇到某晚特定入口机房割接或域名临时调整。最省钱且可靠的稳定性方案是：**1 家支持 Clash 通用订阅的月付主力 + 1 家不同上游系的“一次性不限时流量包”备用**：
- 两者同时导入 **Clash Verge Rev**「配置」列表；
- 平时主力跑日常；遇到极端波动时在客户端单击一下配置文件即可 1 秒切换备用线；
- **关键避坑**：根据档案情报，**Firefly 与微风、飞鸟、一云梯存在同系关系**，选备用时请避开同一上游系。
