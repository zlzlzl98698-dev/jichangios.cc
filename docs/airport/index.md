## 三、选购前五项防踩坑黄金检查单

1. **先确定客户端，再付款买机场**：如果你已装好 Clash Verge Rev、买了 iPhone Shadowrocket 或准备挂 OpenWrt 软路由，务必要看清「仅专属客户端」品牌清单，否则买来也导不进订阅；
2. **首单只用真实月付跑满 7 天晚高峰**：在自己家电信/联通/移动宽带晚上 20:30–22:30 连续抽测几次，满意了第二单再转季付/年付或补充不限时包；
3. **认清“缺测速”与“品牌自述”标签**：在 [独立品牌评测中心](/reviews/) 和 [31 家品牌数据库](/brands/) 中，凡标注 `待核实` 或 `vendor_claimed` 的宣称均无独立实测佐证，不可轻信“全节点 100% 永久解锁”；
4. **留意特价套餐不适用优惠码条款**：百元以内年付小包及不限时永久流量包普遍排除新人 8 折/9 折折扣码，且虚拟服务通常不支持退款；
5. **关键工作准备一条跨系不限时热备**：例如搭配百元档通用订阅不限时包放在 Clash 备用列表，防单一服务商临时抽风。
