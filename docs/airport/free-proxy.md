## 一、免费梯子背后的三种常见真相（为什么“免费”最贵）

任何跨境节点都需要持续支付海外服务器租金与中转/专线带宽费用。当某个工具宣称“永久免费不限流量”时，成本通常会通过以下三种隐性方式转移到用户身上：

1. **利用你的设备充当“共享住宅代理出口”**：部分免费安卓 VPN 或浏览器免费插件会在后台把你的家庭宽带 IP 接入第三方代理池，供陌生人用来做爬虫、刷单甚至违规请求，风险直接落在你的本地宽带上。
2. **中间人流量劫持与广告注入**：部分免费软件诱导用户在系统安装自定义根证书（Root CA），或在下发的 Clash YAML 中悄悄写入 `skip-cert-verify: true` 与恶意 DNS，从而嗅探访问记录甚至篡改下载文件。
3. **虚假“破解版”木马捆绑**：搜索“Clash 免费节点内置版”“小火箭免费破解版”下载来的第三方压缩包，常见包含剪贴板劫持（盗取加密钱包地址）或浏览器 Cookie 窃取程序。

## 二、真实可用性对比：免费公开节点 vs 合规付费/自建

| 比较项目 | 免费公开节点 / 免费梯子 App | 开源客户端 + 合规平价/不限时订阅 |
| :--- | :--- | :--- |
| **晚高峰（20:00–23:00）连通率** | 极差，随时集体失效（寿命数小时到几天） | IEPL/IPLC 专线通常可用且有多地区切换冗余 |
| **Cloudflare / Google 验证** | 每打开一个网页就弹出繁琐人机验证码 | 干净出口节点较少频繁拦截 |
| **ChatGPT / Claude / 流媒体** | 基本不可用（IP 早已进黑名单） | 可针对特定地区节点解锁支持 |
| **客户端安全性** | 来历不明的闭源免费 App 风险极高 | 使用 GitHub 开源 Clash Verge Rev / v2rayNG 并校验哈希 |
| **时间与试错成本** | 每天花半小时找可用订阅、不停掉线重连 | 一次导入配置后长期稳定自动更新 |

## 三、如果确实急需临时应急，必须遵守的四条隔离守则

1. **客户端只用开源正版**：永远只从 GitHub Releases 下载 [Clash Verge Rev](/clash/verge-download)、v2rayNG 或 FlClash，**绝不安装来历不明的“一键免费翻墙 EXE/APK”**。
2. **导入公开 YAML 前先扫一眼危险字段**：用记事本打开配置，检查是否存在 `skip-cert-verify: true`（强制跳过证书校验）或陌生的局域网网段放行修改，发现异常立即删除。
3. **浏览器使用无痕模式且不登录任何账号**：应急节点期间只读公开技术文档、只下载开源镜像（下载后务必核对官方 SHA-256），不要登录微信网页版、邮箱、网盘、交易所或支付平台。
4. **用完立即断连并移除配置**。

## 四、真正省钱且安全的两种低成本替代思路

- **方案 1 · 一次性不限时流量包（适合每月仅用数 GB 的用户）**：如果一年总流量不到 100GB，不必为了“省钱”去冒险找免费梯子。花 ¥99–¥147 购买一张正规品牌的不限时流量包（例如 100GB–247GB 永久不过期），摊下来每年实际开销和几杯奶茶差不多，还能享受专线速度与 Clash 规则分流（详见 [性价比机场指南](/airport/value)）。
- **方案 2 · 个人海外 VPS 自建开源核心**：具备基础 Linux 命令行的开发者，可直接租用合规低价海外 VPS 部署开源 `sing-box`（VLESS-Reality 或 Hysteria 2），数据完全掌控在自己手里。
