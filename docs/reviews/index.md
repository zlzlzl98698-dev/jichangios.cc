# 独立品牌评测中心

本区遵循 **证据优先与透明披露** 原则：所有评测均标明原始资料来源、测试日期与非晚高峰/晚高峰环境；对于缺少实测数据或存在历史版本差异的品牌，直接标注缺口，不以商家宣传话术充当实测结论。完整审计细节请参阅 [评测方法与测试标准](/methodology)。

## 一、三项核心评测准则

1. **可溯源的原始证据**：主要依据《32家机场品牌清单.txt》（含 `2026-10-19` 基准测速与 `2026-08-09` 历史记录）、《光速云品牌信息.txt》、《光速云测试图解锁图 (`2026-08-19`)》以及《机场测速实测资料包 (`2026-08-11` 整理版 V2)》。
2. **严格切分「实测数据」与「品牌方宣称」**：图表中独立区分为 `Measured Data`（实测数据）、`Vendor Claimed`（品牌方宣称）、`Partial / 视节点` 与 `Not Tested`（暂未测试）。
3. **商业合作利益隔离**：部分品牌包含已披露的推广链接，评测结论不随佣金率高低调整排序；底部仅在披露提示后提供对应品牌核实入口。

## 三、如何阅读评测文章才不踩坑？

- **先看客户端开放度与真实单月价**：判断自己手头 Clash/小火箭/软路由能不能导进去、最低花一二十元试一个月可不可行；
- **再对照本地运营商与测试窗口**：注意截图是下午闲时跑满机房千兆带宽，还是晚 21 点高峰期测试；
- **多机场切忌买在同一系后台**：例如需要主力 + 备用两家防单点故障时，参考 [风险情报审计](/resources/intelligence) 跨开同系组合。
