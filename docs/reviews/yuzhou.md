## 一、2026-08-11 21:04 晚间 VLESS 实测原图逐区解读

<NetworkPerformanceReport slug="yuzhou" />

这是全站图包中**少有的刚好落在晚高峰 21:04 窗口的 VLESS 测试**（`main 4.3.3 / miaosu 4.7.0`，珠海联通 9Gbps 32 线程，共 50 个 VLESS 节点），阅读时注意结合测试环境还原现实预期：

| 测试区域 | 2026-08-11 21:04 原图读数 | 异常/波动如实记录 |
| :--- | :--- | :--- |
| **香港 (01–15)** | 香港 02–15 均速达 `470–550 MB/s`（9Gbps 测试机跑满表现），TLS RTT 约 `96–121ms`，UDP 多为 `FullCone` | **香港 01 录得 `0.00B`（完全失效）** |
| **新加坡** | 正常节点均速 `331–523 MB/s` | **新加坡 07 录得 `9.60KB`（接近失联）** |
| **台湾** | 节点分布稳定，均速约 **`29–77 MB/s`** | 吞吐远低于港新但够常规高清使用 |
| **日本** | 均速跨度大（**`22–169 MB/s`**） | 部分日本节点 **HTTPS 延迟飙高至 `1700–2091ms`**，看重日区低延迟网页响应要谨慎 |
| **美国** | 稳定维持在 **`8.3–12.4 MB/s`** | 远距离速率偏保守 |

> 读图修正提醒：珠海联通 `9Gbps` 多线程测试台旨在压出机场服务端物理出口天花板，绝不代表家用 300M/1000M 宽带实际拉文件就能跑出 500MB/s；更值得看的是 **21:04 节点可用率（48/50 正常）与日本 HTTPS 延迟波动**。
